# AI Study Coach — SQLite edition

A Flask study-session API with rule-based insights and recommendations, plus an Expo/React Native mobile client. The backend uses `backend/study_coach.db` and runs on port 5000.

- [Developer guide: setup, mobile connection, API, and test limitations](docs/PROJECT_GUIDE.md)
- [Source, commands, and route reference](docs/REFERENCE.md)
- [Contributing](CONTRIBUTING.md)

This edition has demonstration mobile login/group behavior and known stale client endpoint mappings. The guide identifies the actual backend routes. Preserve the tracked SQLite data and use a disposable checkout for tests that drop tables.

Historical architecture and feature notes remain in the repository; the current source reference identifies the files actually present. This project was designed for educational use as part of an internship program.
